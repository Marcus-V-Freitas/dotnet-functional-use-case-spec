# dotnet-functional-use-case-spec — Gemini Gem

Versão para Gemini Gem da persona focada em **funcionalidades/casos de uso**.

## Configuração

1. Crie um Gem chamado `.NET Functional Use Case Architect`.
2. Copie `GEM-INSTRUCTIONS.md` para as instruções.
3. Adicione os arquivos de `knowledge/`.
4. Forneça o repositório/arquivos do projeto na conversa.

## Exemplo

```text
Analise a funcionalidade ProcessPayment.

Ela pode estar implementada como Handler, UseCase, Consumer ou Service.

Gere apenas sua especificação contendo:
- input payload;
- outputs possíveis;
- cenários;
- C4;
- integrações;
- riscos;
- avaliação de decomposição;
- testes AAA.
```
